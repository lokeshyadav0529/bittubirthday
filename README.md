# Bittu × Laddu ❤️

Luxury romantic birthday experience made with plain HTML, CSS and JavaScript. No framework, npm, Node.js, or build step is required.

## Open the website

Open `index.html` in a modern browser. For browser security around local audio, a simple static server such as GitHub Pages is recommended after uploading the project.

## Personal files

- Put Laddu's original voice recording at `public/audio/Bittu.m4a`.
- Optional background music goes at `public/audio/background-music.mp3`.
- Add real photos at `public/images/memories/memory-01.jpg` through `memory-05.jpg` (JPG/PNG/WebP work). Captions and image order are set in `js/main.js`.
- No supplied audio or photos are included; the app shows graceful setup messages and replaceable neutral frames.

## Project files

- `index.html` — page structure
- `css/style.css` — responsive visual design and animations
- `js/main.js` — scene flow and editable gallery configuration
- `js/animations.js` — petals and particle effects
- `js/cake.js` — wish, knife interaction, and separated cake halves
- `js/audio.js` — native audio playback and controls
- `js/gallery.js` — photo gallery and lightbox
